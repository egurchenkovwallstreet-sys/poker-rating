# Краткое ТЗ (актуальная выжимка)

Проект: **Telegram Mini App «Покерный рейтинг»** — статистика покера для одного клуба.

## Принципы

- Данные в **Cloudflare Durable Objects** (SQLite)
- **Mini App** — React на **GitHub Pages**
- **Бот** — регистрация, анонсы игр, админка; **Mini App** — просмотр статистики
- Без VPS, Vercel, Firebase; из РФ без VPN

## Стек

- Worker: TypeScript, Hono, grammY, DO
- Mini App: React 18, Vite, Tailwind, @telegram-apps/sdk-react, recharts

## Роли

- **Админ:** `ADMIN_IDS` в wrangler — анонс игр, старт, ввод/правка результатов (правка с опросом).
- **Игрок:** `/register` в боте, RSVP на игры, Mini App только читает.

## Игроки

- Самoregистрация, **уникальное имя**, профиль меняет **только сам**.
- Аватар — из профиля Telegram (`/avatar`).
- Demo-игроки `/seeddemo` — для таблиц, **без** telegram_id, RSVP не работает.

## Игра (целевой процесс)

1. Админ: дата + билет + лимит мест → рассылка **зарегистрированным** в личку.
2. «Участvую» / «Нет»; места по очереди; закрытие при лимите или **Старт**.
3. Уведомление всем о каждой новой записи; общий список в тексте приглашения.
4. После игры — результаты (первичный ввод без голосования).
5. Изменение позже — **>50%** участников этой игры в таблице результатов.
