# Краткое ТЗ (актуальная выжимка)

Проект: **Telegram Mini App «Покерный рейтинг»** — статистика покера для одного клуба.

## Принципы

- Данные в **Cloudflare Durable Objects** (SQLite)
- **Mini App** — React на **GitHub Pages**
- **Бот** — регистрация, анонсы, **админка только в чате**
- **Mini App** — **только просмотр статистики** (не админка)
- Без VPS; из РФ без VPN

## Стек

- Worker: TypeScript, Hono, grammY, DO
- Mini App: React 18, Vite, Tailwind, @telegram-apps/sdk-react, recharts

## Роли

- **Админ** (`ADMIN_IDS`): игры и результаты в **боте** (inline-меню, `/admin`).
- **Игрок:** `/register`, RSVP, статистика через кнопку **📊 Статистика** → Mini App.

## Интерфейс бота (фиксировано)

- Низ чата: **Регистрация** / **Статистика** / у админа ещё **Админ**
- Сбоку у поля ввода: **обычное** меню Telegram (не Web App «Статистика»); сброс `/fixmenu`, `/start`
- Статистика открывается через **inline** «Открыть статистику» (не `web_app` на reply-клавиатуре)

## Игроки

- Уникальное имя, профиль меняет только сам, `/avatar` из Telegram
- `/seeddemo` — demo-игроки и игры **без** `telegram_id` (для таблиц в Mini App)

## Игра

1. Анонс → RSVP → старт → `open`
2. Ввод результатов админом → `finished`
3. Правка позже — **>50%** участников игры (ещё не сделано)
